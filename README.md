# متجر إلكتروني بسيط (Ecommerce Store)

مشروع متجر إلكتروني كامل: عرض منتجات، سلة مشتريات، إتمام طلب، ولوحة تحكم للأدمن.

## التقنيات المستخدمة
- **Backend**: Node.js + Express + SQLite (better-sqlite3)
- **Frontend**: React + Vite + React Router

## هيكل المشروع
```
ecommerce-project/
├── backend/          # السيرفر والـ API وقاعدة البيانات
│   └── src/
│       ├── routes/         # تعريف الروابط (endpoints)
│       ├── controllers/    # المنطق الفعلي لكل route
│       ├── db.js           # الاتصال بقاعدة البيانات + إنشاء الجداول
│       ├── seed.js         # بيانات منتجات تجريبية
│       └── server.js       # نقطة تشغيل السيرفر
└── frontend/         # الموقع اللي بيشوفه المستخدم
    └── src/
        ├── pages/           # الصفحات (رئيسية، تفاصيل منتج، سلة، إلخ)
        ├── components/      # أجزاء قابلة لإعادة الاستخدام (بطاقة منتج، فورم)
        ├── context/         # إدارة حالة السلة
        └── services/        # كل الاتصال بالـ Backend من مكان واحد
```

## طريقة التشغيل محليًا

المشروع فيه جزئين لازم يشتغلوا **مع بعض**، كل واحد في Terminal منفصل.

### 1) تشغيل الباك اند

> ⚠️ **مهم جدًا لو عندك نسخة شغالة قبل كده:** لازم تحذف ملف `backend/database.sqlite` القديم (لو موجود) قبل ما تشغّل، لأن شكل الجداول اتغيّر (العنوان بقى 4 خانات بدل خانة واحدة). لو الملف مش موجود أصلاً، تجاهل الخطوة دي.

```bash
cd backend
npm install
npm run seed     # أول مرة بس، عشان يحط منتجات تجريبية في قاعدة البيانات
npm run dev
```

هيشتغل على: `http://localhost:5000`
للتأكد إنه شغال، افتح: `http://localhost:5000/api/health`

### 2) تشغيل الفرونت اند

في Terminal تاني:

```bash
cd frontend
npm install
npm run dev
```

هيديك رابط زي: `http://localhost:5173` — افتحه في المتصفح.

## الصفحات المتاحة
| الصفحة | الرابط |
|---|---|
| الرئيسية (بانر + عرض المنتجات) | `/` |
| تفاصيل منتج (+ بانر خاص + منتجات مشابهة) | `/product/:id` |
| السلة | `/cart` |
| إتمام الطلب (عنوان 4 خانات + تحقق من التليفون) | `/checkout` |
| نجاح الطلب | `/order-success/:orderId` |
| لوحة التحكم (منتجات + طلبات + إعدادات) | `/admin` |

## أهم الميزات الجديدة
- **رفع صور فعلي** للمنتجات والبانرات (jpg فقط) من لوحة التحكم، بدل روابط يدوية
- **بانر قابل للتغيير** لكل من الصفحة الرئيسية وصفحة تفاصيل المنتج
- **منتجات مشابهة** تظهر تلقائيًا أسفل كل صفحة منتج
- **عرض أفقي للمنتجات** (جنب بعض) مع أسهم تنقل
- **تحقق من رقم التليفون**: لازم يكون 11 رقم ويبدأ بـ 01، وإلا هتظهر رسالة خطأ فورية
- **عنوان مقسّم لـ 4 خانات**: المحافظة، المركز، المنطقة، وعلامة مميزة (اختيارية)
- **رسوم توصيل ثابتة (50 جنيه)** بتتضاف تلقائيًا على أي طلب
- **ملاحظات أدمن** على كل طلب (مش ظاهرة للعميل، بس الأدمن يقدر يكتبها ويحفظها)
- **روابط واتساب وتيك توك** قابلة للتعديل من لوحة التحكم، وبتظهر كأيقونات في أعلى الموقع

> ⚠️ ملاحظة: صفحة `/admin` لسه مفتوحة لأي حد يعرف الرابط، من غير تسجيل دخول. مناسب للتجربة، لكن لو الموقع هيتنشر فعليًا لازم تتحمي.

## أهم روابط الـ API (Backend)

| Method | الرابط | الوظيفة |
|---|---|---|
| GET | `/api/products` | كل المنتجات |
| GET | `/api/products/:id` | منتج واحد |
| POST | `/api/products` | إضافة منتج (Admin) |
| PUT | `/api/products/:id` | تعديل منتج (Admin) |
| POST | `/api/orders` | إرسال طلب جديد |
| GET | `/api/orders` | كل الطلبات (Admin) |
| GET | `/api/orders/:id` | تفاصيل طلب واحد (Admin) |
